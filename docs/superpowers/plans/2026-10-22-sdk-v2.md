# Standalone SDK Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tested typed SDK and working game scaffolder in a private independent repository.

**Architecture:** Compile dependency-free TypeScript modules to flat browser-compatible ESM. Keep HTTP, transport, sessions and public types separate, re-export through mini-engine.ts. CLI generates self-contained trusted host-runtime assets served by the engine.

**Tech Stack:** TypeScript, Node test runner, native fetch/WebSocket, npm, GitHub Actions.

---
